---
description: Manages allow/ask/deny rules for tool permissions.
---

Manage tool permission rules. Allow the user to:

- View current allow/ask/deny rules
- Add new rules (allow/ask/deny) scoped to tools or patterns
- Remove existing rules
- Move rules between user, project, and local settings

Settings are stored in `.claude/settings.json` (project) or `~/.claude/settings.json` (user).
