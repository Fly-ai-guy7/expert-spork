---
description: Analyzes pending changes for security vulnerabilities.
---

Review the pending changes on the current branch for security vulnerabilities. Check for issues such as:

- Injection flaws (SQL, command, XSS)
- Hardcoded secrets or credentials
- Insecure deserialization
- Broken authentication or authorization
- Insecure cryptographic storage or transport
- Path traversal and SSRF
- Insecure defaults

Report findings grouped by severity with file:line references and suggested fixes.
