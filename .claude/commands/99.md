Run the research bot in 99 Mode: high-quality deep research pass across all Egyptian topics.

Execute the following in the project root:

```bash
./run.sh --mode 99
```

- 10 results per source (2x normal)
- All 8 Egyptian topics processed
- Runs once then exits
- Generates research/SUMMARY_REPORT.md with full stats

After the run completes:
1. Read research/SUMMARY_REPORT.md
2. List all updated files in the research/ directory
3. Report back with a summary of what was fetched — topics covered, paper count, news article count, and any errors encountered
